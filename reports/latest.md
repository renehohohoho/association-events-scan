## 查證限制

1. **asq.org/conferences 抓取失敗**：被 Cloudflare 安全驗證擋下（HTTP 403，"Performing security verification"），用一般 HTTP 請求和無頭 Chromium 都一樣。本週沒有掃描這個來源，也沒有用搜尋摘要替代。ASQ 全國性研討會多為付費，但仍屬未覆蓋。
2. **ASQ 會員行事曆（my.asq.org/events/calendar）**：無頭 Chromium 渲染成功，把每頁筆數切到最大，一次讀到全部 152 筆。依主題與地點初篩後，逐場打開了 44 個詳情頁核價；其餘場次因明顯不相關（地方聚會、參訪、外州實體活動等）沒有打開詳情頁。
3. **OACETT**：公開頁面全文讀取成功；輪播中隱藏的項目也從原始 HTML 讀到了。價格取自該頁每個項目的 "Cost:" 欄位，沒有另外打開各外部報名頁。
4. **OSPE members.ospe.on.ca/events**：網頁預設先顯示隨選課程，所以改用網站公開的 The Events Calendar REST API（/wp-json/tribe/events/v1/events，不需登入）取出涵蓋區間內的 13 場，再逐場打開詳情頁核價。若有場次未經這支 API 公開，本報告不會包含。
5. **OSPE EngLearn（learn.ospe.on.ca）**：只有隨選課程與錄影，沒有涵蓋區間內的排定活動，頁面上也沒有找到免費項目。
6. **CTTAM**：首頁、/event（顯示 "Nothing Found"）與最新消息頁都沒有活動資訊，最新消息停在 2026-05-25。其活動多以 email 公告，公開頁查不到屬預期。
7. 時區換算依各詳情頁標示的時區；Phoenix 全年使用 MST（UTC−7）。
